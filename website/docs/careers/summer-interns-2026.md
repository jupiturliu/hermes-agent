# Summer 2026 Internships

Nous Research is opening applications for our first summer intern cohort.

We are looking for AI-native builders who want to work close to the frontier of agent systems: terminal agents, tool use, skills, memory, messaging gateways, evaluation loops, and practical workflows that help people use AI systems every day.

This is a project-based internship. You should expect to ship real work, write clearly, use AI tools aggressively, and leave behind artifacts that keep compounding after the summer ends.

## Open tracks

### AI Agent Engineering Intern

Build and improve the systems behind Hermes Agent: tools, skills, memory, gateways, evaluations, dashboards, and developer workflows.

You may be a fit if you:

- have shipped software projects outside of class
- can read and modify Python and TypeScript
- are comfortable using AI coding agents as part of your workflow
- care about reliability, testing, and clear developer experience
- like turning rough workflows into reusable tools

Example projects:

- improve skills, routing, and evaluation loops
- add or harden messaging / webhook integrations
- build small internal tools for agent observability
- improve docs, onboarding, and examples for real users

### AI Product / Research Ops Intern

Help turn agent capabilities into repeatable user workflows: onboarding, documentation, research packets, user interviews, support loops, and product-quality examples.

You may be a fit if you:

- write clearly and structure ambiguous information well
- are comfortable using AI tools to research, summarize, test, and iterate
- can turn messy notes into crisp playbooks or product specs
- like user workflows, product thinking, and operational detail
- can move between research, documentation, and lightweight technical work

Example projects:

- create product-grade use-case playbooks for Hermes Agent
- analyze real agent workflows and convert lessons into skills
- build onboarding and support artifacts for new users
- help design repeatable evaluation and feedback loops

## What we value

We care less about credentials and more about evidence.

Strong candidates usually show:

- high learning velocity
- clear writing
- strong work samples
- AI-native execution habits
- comfort with ambiguity
- low-ego iteration
- ability to ship small things quickly

You do not need to already know the whole Hermes codebase. You do need to be curious, rigorous, and willing to work in public artifacts: issues, docs, tests, notes, and pull requests.

## How we evaluate

Our process is designed around evidence, not vibes.

Typical flow:

1. Application review
2. Short intro conversation
3. Work-sample exercise related to the track
4. Final conversation about fit, project scope, and summer goals

We will not ask you to perform unpaid production work. Work samples are scoped to evaluate how you think, write, and build.

## How to apply

Email your application to [internships@nousresearch.com](mailto:internships@nousresearch.com) with the subject:

```text
Summer 2026 Internship - <Your Name> - <Track>
```

Include:

- resume or short background summary
- GitHub / portfolio / writing samples / project links
- which track you are applying for
- 3-5 sentences on why Hermes Agent or AI agents interest you
- availability and location / timezone

If you are unsure which track fits, apply anyway and say what kind of work you want to do.

## Equal opportunity

We evaluate candidates based on role-relevant evidence: skills, work samples, communication, learning velocity, and project fit. We do not use protected-class characteristics in hiring decisions.
